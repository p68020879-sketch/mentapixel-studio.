Preguntas frecuentes

¿Qué recibo al comprar una plantilla?

Los archivos de la página web, incluyendo HTML, CSS y JavaScript cuando corresponda, junto con instrucciones de publicación. Confirma qué incluye cada producto antes de pagar.

¿Puedo publicar la página en internet?

Sí. Las plantillas estáticas pueden publicarse en servicios de alojamiento compatibles. El dominio y el alojamiento pueden tener costos adicionales.

¿Las plantillas incluyen una tienda con pagos reales?

No necesariamente. Un carrito de demostración no procesa pagos reales. Las integraciones de pago, bases de datos y sistemas de pedidos requieren configuración adicional.

¿Puedo pedir una página diferente?

Sí. Puedes solicitar una página personalizada y recibir una cotización según las características del proyecto.
